# CIPT Quiz System V1

一个面向中文学习者的 CIPT 刷题工具。整个应用只有一个 `index.html`，无需安装依赖、无需后端，也不需要联网。

## 主要功能

- 中英双语题干与选项，可一键隐藏中文进行自测
- 长句拆解、逻辑词提示与题内关键词解释
- 答题解析、排除思路和一句话记忆点
- 错题本、低把握题、收藏题统一复习
- 按知识域筛选、随机排序、学习模式 / 自测模式
- 术语词库中英搜索
- 使用浏览器 `localStorage` 保存进度，支持 JSON 导入和导出
- 适配电脑与手机，支持键盘快捷键

## 使用

直接下载并双击打开 `index.html`。

也可以在仓库目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `1` - `4` | 选择 A - D |
| `Enter` | 提交答案 / 下一题 |
| `T` | 显示或隐藏中文 |
| `F` | 收藏或取消收藏 |

## 题库说明

V1 内置 24 道原创 CIPT 风格练习题和 30 个常用术语，用于演示系统功能和辅助学习，不是 IAPP 官方试题，也不代表真实考试内容。

如需扩充题库，可在 `index.html` 中编辑：

- `TERMS`：术语词库
- `QUESTIONS`：题目、选项、答案、拆句与解析

## 数据与隐私

学习数据只保存在当前浏览器。清除浏览器站点数据会删除进度，换设备前请在“学习数据”中导出 JSON 备份。
